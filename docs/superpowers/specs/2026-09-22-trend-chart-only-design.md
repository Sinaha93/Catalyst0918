# 월별 계획·실적 그래프 전용 시트 설계

## 목표

`월별 계획·실적` 시트는 보고용 그래프만 보여주고, 누적 계획·실적 원천은 `종합3(누적)`에서 한 번만 관리한다.

## 현재 구조

- `종합3(누적)`은 연도·월·거래처·구분·항목·값의 정규화된 누적 이력을 보관한다.
- `월별 계획·실적`의 `B30:R36`은 그래프 원본인 13개월 요약표다.
- `B66:AT101`은 거래처별 누적표이고, `B104:AH148`은 이를 `TRANSPOSE`한 중복 보조표다.
- 기존 양식의 일부 수식은 보조표를 참조하지만 보고서 생성기가 해당 결과 셀을 직접 다시 쓴다.

## 변경 설계

1. 보고서 생성기는 종전처럼 `종합3(누적)`과 확정 마감 스냅샷으로 13개월 이력을 계산한다.
2. `B30:R36`에는 그래프에 필요한 월·계획·실적·평균 값만 유지한다.
3. `B30:R148` 행은 화면에서 숨겨 사용자가 그래프만 보게 한다.
4. 숨긴 원본도 그래프에 표시되도록 모든 차트의 `PlotVisibleOnly`를 `False`로 설정한다.
5. 중복 데이터인 `B66:AT148`은 출력 파일에서 비운다.
6. `종합3(누적)` 시트와 다른 보고 시트는 유지한다.

## 오류 방지와 검증

- 정리 로직은 별도 함수로 두고 단위 테스트에서 숨김 범위, 비우는 범위, 차트 설정을 검증한다.
- 전체 테스트를 실행한다.
- 실제 Excel 보고서를 생성해 `월별 계획·실적`의 차트 존재, 숨김 행, 중복표 제거, 수식 오류 부재를 확인한다.

## 범위 밖

- `종합3(누적)`의 형식 변경
- 그래프 디자인·색상·계열 변경
- 과거 원본 Excel 파일 삭제
